# AGENTX - Global Intelligence & Automation

![AGENTX Live Preview](public/images/civic-nodes/ezgif-frame-001.jpg)

**Live Demo:** [https://zippy-melba-138f69.netlify.app/](https://phenomenal-pastelito-1916e9.netlify.app/)

AGENTX is a highly premium, modern, "Scrollytelling" corporate website built for a visionary AI startup. The platform highlights high-impact small projects powered by **Machine Learning**, **Agentic AI**, and **Generative AI**. It features a founders spotlight for Yashraj Panda & Ritam Patra.

## ✨ Features
* **Scrollytelling 3D Canvas:** Interactive, scroll-driven 3D image sequences using HTML5 Canvas for peak performance.
* **Framer Motion Animations:** Smooth, synchronized text fading, layout transitions, and subtle glowing background orbs.
* **Premium Dark Mode UI:** Built with Tailwind CSS, featuring glassmorphism elements, custom scrollbars, and neon-cyan cyber aesthetics.
* **Static Export Ready:** 100% configured for static hosting (`output: 'export'`).

## 🛠 Tech Stack
* **Framework:** Next.js 14 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React

## 🚀 Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## 📦 Deployment (Static Export)
To build the application for static hosting (like Netlify, GitHub Pages, or Vercel):
```bash
npm run build
```
The output will be generated in the `out/` directory.
